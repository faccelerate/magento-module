# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Send an email to **security@faccelerate.ai** (placeholder: replace with the final address before the first release) with:

- what you found and where (file, setting or URL),
- the steps to reproduce it,
- the Magento or Mage-OS version, PHP version and module version.

We confirm receipt within 3 working days, tell you what we plan to do within 10 working days, and credit you in the changelog if you want that. Please give us a reasonable time to ship a fix before you publish details.

## Supported versions

We fix security problems in the latest release.

## Scope

This policy covers the `Faccelerate_Connect` module (`faccelerate/module-magento`). For problems in the Faccelerate service itself, use the same address.
